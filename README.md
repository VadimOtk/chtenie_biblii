# Bible Telegram Bot

Telegram-бот для ежедневного чтения Библии и анонимных размышлений.

## Возможности V1
- Администратор вручную задаёт сегодняшнее чтение и вопрос дня.
- Пользователь читает материал и отправляет своё размышление.
- Размышление проходит модерацию.
- После публикации оно отображается анонимно.
- Опубликованное размышление нельзя изменить или удалить пользователю.
- Пользователь может отправить админу просьбу изменить опубликованное размышление.
- Администраторы управляются через Telegram ID.
- Главный администратор может добавлять и удалять дополнительных админов.
- Раздел «Библия — это история» позволяет админу вручную добавлять события.
- Данные хранятся в SQLite, поэтому для первого запуска отдельный сервер БД не нужен.

## Запуск локально

1. Установить Python 3.11+.
2. Создать Telegram-бота через BotFather и получить токен.
3. Скопировать `.env.example` в `.env`.
4. Заполнить `BOT_TOKEN` и `OWNER_ID`.
5. Установить зависимости:

```bash
pip install -r requirements.txt
```

6. Запустить:

```bash
python bot.py
```

## GitHub / Bothost

Не загружайте `.env` в GitHub.

Для хостинга задайте переменные окружения:
- `BOT_TOKEN` — токен бота.
- `OWNER_ID` — Telegram ID главного администратора.

Команда запуска:
```bash
python bot.py
```

База `data/bot.sqlite3` создаётся автоматически.

## Администраторы

`OWNER_ID` — главный администратор. Его нельзя удалить из самого бота.

Главный администратор может:
- добавить админа по Telegram ID;
- удалить дополнительного админа;
- посмотреть список админов.

Дополнительные админы могут модерировать публикации и менять содержимое бота, но не могут управлять списком администраторов.

## Важное про анонимность

Публично имя, username и Telegram ID автора размышления не показываются.

Telegram ID сохраняется в базе для технической работы модерации и обработки запросов. Это не означает абсолютную анонимность от владельца/администраторов Telegram или хостинга.
