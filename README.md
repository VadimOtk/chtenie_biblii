# Библия на каждый день

Telegram-бот + Mini App на Python/aiogram.

## Возможности

- ежедневное чтение, задаваемое администратором;
- вопрос дня;
- анонимные размышления с модерацией;
- запросы на изменение опубликованного размышления;
- резервные администраторы;
- раздел «Библия — это история»;
- прогресс чтения;
- ежедневные уведомления;
- красивый Telegram Mini App;
- единая SQLite-база для бота и Mini App.

## Переменные окружения

```env
BOT_TOKEN=...
OWNER_ID=...
BOT_TIMEZONE=Asia/Tomsk
NOTIFICATION_TIME=08:00
WEBAPP_URL=https://your-subdomain.bothost.ru
PORT=3000
```

`WEBAPP_URL` — HTTPS-адрес Mini App, который выдаёт/подключает Bothost.
`PORT` должен совпадать с портом веб-сервиса в настройках Bothost. По умолчанию используется 3000.

## Запуск

```bash
pip install -r requirements.txt
python bot.py
```

Бот работает через polling, а Mini App/API одновременно слушают `0.0.0.0:$PORT`.

## Mini App

Статика находится в `webapp/`.

API:

- `GET /api/health`
- `GET /api/state`
- `POST /api/mark-read`
- `POST /api/reflections`
- `POST /api/edit-request`

Mini App передаёт Telegram `initData` в заголовке `X-Telegram-Init-Data`. Сервер проверяет подпись перед доступом к данным пользователя.

После указания `WEBAPP_URL` бот автоматически устанавливает кнопку меню Telegram «Открыть приложение».

## Важное про текст Библии

Поле текста сегодняшнего отрывка хранится в базе и показывается внутри Mini App. Администратор может добавить текст при создании/изменении сегодняшнего чтения.

Для больших отрывков лучше следующим этапом подключить локальную структурированную базу текста Библии по книгам/главам/стихам, чтобы администратор выбирал диапазон, а не вставлял текст вручную.
